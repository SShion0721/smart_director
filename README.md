# Smart Director

Smart Director 是一个面向 Left 4 Dead 2 的 SourceMod 特感导演插件。它不直接替换游戏的全部 Director 行为，而是接管普通特感的配额、队列、目标选择和生成位置，并保留 Tank、尸潮与难度档位相关的独立规则。

## 运行流程

一次普通补特由以下阶段组成：

1. **状态缓存**
   - 事件回调维护玩家是否在线、队伍、存活状态、倒地状态、被控状态和胆汁状态。
   - 位掩码用于快速枚举存活生还者和普通特感。
   - Flow 缓存只在玩家移动超过阈值后更新，读取失败时保留上一次有效值。

2. **波次编排**
   - 主循环根据最大特感数量、当前存活数量、在途数量和生成队列判断是否需要补充。
   - 阵容规则决定控制类与范围类特感的比例。
   - 队列中的每个元素表示一个待生成的特感类型。

3. **目标选择**
   - 默认优先选择进度最高且未倒地、未被控的生还者。
   - 如果没有满足条件的目标，则回退到任意存活生还者。

4. **候选位置搜索**
   - 地图 NavArea 按 Flow 百分比划分为 101 个桶。
   - 搜索从目标所在进度附近开始，并对前方区域给予更高优先级。
   - 候选点必须满足距离、可见性、Hull 占位、Nav 高度和近期生成间隔等硬约束。
   - 当前规则评分在合法候选中选择最终位置。

5. **生成与状态同步**
   - 成功生成后记录生成时间、幽灵占位和调试信息。
   - 在途计数在请求进入队列时增加，在成功或失败后及时结算。
   - 如果 Nav 搜索失败，则回退到游戏引擎的随机特感生成位置接口。

## 设计边界

候选点搜索分为两层：

- **硬约束层**负责保证位置可用，包括距离、可见性、碰撞和地图进度范围。任何学习模型都不能绕过这一层。
- **排序层**负责在合法候选之间比较质量。当前版本使用手工规则；实验分支可以在这一层或特感类型选择层加入 NNUE。

这样划分的原因是，神经网络适合学习候选之间的相对价值，但不应承担服务器安全、合法性和状态恢复职责。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `smart_director.sp` | 依赖声明和模块装配 |
| `config.inc` | 常量、ConVar、全局状态和数据结构 |
| `api.inc` | Left4DHooks 与生成相关接口封装 |
| `nav_cache_build.inc` | NavArea 采样、Flow 分桶和异常 Flow 映射 |
| `nav_cache_io.inc` | Nav 分桶缓存的读取与写入 |
| `nav_helpers.inc` | Flow、安全读取、桶顺序、Trace 和通用 Nav 工具 |
| `lifecycle_setup.inc` | 插件初始化、事件注册和资源准备 |
| `lifecycle_run.inc` | 回合状态、主循环、队列处理和难度规则 |
| `state_spawn.inc` | 玩家状态缓存、特感清理、位置生成和执行生成 |
| `waves_debug.inc` | 波次编排、类型计数和调试命令 |
| `logic_admin.inc` | 管理命令、概率逻辑和特殊规则 |
| `phantom.inc` | 幻听效果 |

## 依赖

- SourceMod 1.12 或兼容版本
- SDKTools
- SDKHooks
- Left4DHooks
- SourceScramble
- `function_data.txt` 中对应的 `CDirector::GetMaxPlayerZombies` MemoryPatch 配置

## 编译

将源码放入 SourceMod 的 `addons/sourcemod/scripting/` 目录，并保证依赖的 include 文件可用：

```text
spcomp smart_director.sp
```

当前仓库没有配置持续集成。提交前至少需要执行 SourcePawn 编译，并在测试服务器检查以下行为：

- 回合开始和结束时定时器能够正确创建与释放；
- Nav 缓存能够加载或重建；
- 特感数量不会长期超过 `sd_max_si`；
- 生成失败后在途数量不会残留；
- 引擎回退路径仍能生成合法特感。

## 实验开发原则

学习型评估器应放在独立分支，并满足以下条件：

- 默认关闭；
- 支持 shadow 模式，只记录模型决策，不改变实际生成；
- 模型或扩展不可用时自动回退到规则系统；
- 能记录模型选择、规则选择、各类评分和最终结果；
- 通过固定地图、固定配置和足够回合数进行 A/B 对比。
