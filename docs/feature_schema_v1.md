# 特征布局 v1

106 个二值输入通过四个 32 位 word 传输，索引从 0 开始。扩展按 `shared OR candidate` 合并。特征定义位于 `include/sd_nnue_bridge.inc`。

## 共享状态

| 索引 | 含义 |
| --- | --- |
| 0 | 所有存活生还者 HP ≥ 80 且未倒地 |
| 1 / 2 | 至少一人 / 两人倒地 |
| 3 | 已连接的生还者中有人死亡 |
| 8 | 存活生还者中有人被胆汁覆盖 |
| 9 / 10 | 队伍最大两两距离 < 400 / > 1200 |
| 17–22 | Hunter、Smoker、Boomer、Charger、Spitter、Jockey 存活 |
| 23–26 | Hunter、Smoker、Charger、Jockey 正在控制目标 |
| 28 / 29 | 插件尸潮模式 / Tank 存活 |
| 31 / 32 | 有效平均 Flow > 50% / > 80% |
| 35 / 36 | 有存活生还者 HP < 40 / < 20 |
| 38 | 存活生还者平均 HP < 50 |
| 43 / 44 | 至少两只 Hunter / Smoker |
| 45 | 普通特感存活数与 pending 之和 ≥ 6 |
| 56 | 终章地图 |
| 74–78 | 平均 Flow 桶：[0,20)、[20,40)、[40,60)、[60,80)、[80,100] |
| 79–82 | 平均 HP 桶：<25、[25,50)、[50,75)、≥75 |

HP 使用永久血量，28 表示插件的尸潮模式。未列出的共享位为 0。

## 候选特征

| 索引 | 含义 |
| --- | --- |
| 87 / 88 / 89 | 距离 <300 / [300,600) / >800 |
| 90 / 91 | 高于目标 >100 / 低于目标 >50 |
| 92 / 93 | 候选 Flow 桶在领先生还者之前 / 不在之前 |
| 94 / 95 | 隐藏 / 暴露；当前排序路径均不设置，表示未知 |
| 100–105 | Smoker、Boomer、Hunter、Spitter、Jockey、Charger one-hot |

距离 [600,800] 不设置 87–89。可见性在排序后查询，避免构造输入时先对整批候选执行 LOS。训练数据应沿用这一含义。

## 特征设计

这一版布局用于当前推理接口，后续可以调整分桶、增加连续量或补充状态。训练数据、特征提取与模型必须使用同一套定义。输入是否适合差分更新及后续设计方向见 [NNUE.md](../NNUE.md#输入特征与增量更新)。
